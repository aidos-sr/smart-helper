# Gemini для Smart Helper

Код поддерживает прямой Gemini API для чата, инструментов, планов, карточек и тестов. Изображения и PDF передаются как inlineData; текстовые файлы остаются текстом. Ключ Google AI Studio отличается от Google OAuth Client Secret, который нужен для входа на сайт.

## Подключение на Vercel

1. Создайте Gemini API key в https://aistudio.google.com/apikey. Посмотрите доступную квоту, тариф и правила обработки данных вашего проекта. Бесплатный доступ зависит от модели и аккаунта; интеграция не гарантирует бесплатные запросы.
2. Откройте проект Smart Helper в Vercel → Settings → Environment Variables. Добавьте для Production:

| Name             | Value                                                             |
| ---------------- | ----------------------------------------------------------------- |
| `AI_PROVIDER`    | `gemini`                                                          |
| `GEMINI_API_KEY` | Ключ из Google AI Studio                                          |
| `GEMINI_MODEL`   | `gemini-3.8-flash` или другая доступная совместимая Gemini-модель |

3. Сохраните переменные и сделайте Redeploy последнего production deployment. Ключ вводится только в Vercel; не используйте префикс VITE\_, не добавляйте ключ в Git, чат или скриншоты.
4. Войдите на сайт и отправьте один короткий запрос. Затем проверьте тест из 5 вопросов и PDF/фото на контролируемых материалах. До ввода ключа реальная генерация Gemini не проверена.

## Поведение и ограничения

- Без `AI_PROVIDER=gemini` приложение продолжает работать через OpenRouter. Автоматического переключения между ключами/сервисами нет: ошибка Gemini не тратит квоту OpenRouter.
- Прямой режим использует одну выбранную модель без перебора резервных моделей. Сохранены общий бюджет попыток, ограничения запросов, отмена, дедлайны и серверная проверка результатов. Допускается существующая ограниченная коррекция некорректного JSON/продолжение обрезанного ответа.
- Ошибки лимита Gemini останавливают повторы; cooldown хранится отдельно от OpenRouter. Сырые сообщения Google и ключ не передаются клиенту.
- Существующие ограничения стоимости через reserve_ai_cost продолжают действовать как предварительная оценка. `AI_MAX_PRICE_PER_MILLION` нужно установить не ниже наибольшей ставки выбранной модели за входные/выходные токены с учётом thinking. Это не гарантированный денежный потолок: также настройте доступные квоты и контроль расходов в Google Cloud. OpenRouter max_price не применяется к прямому Gemini.
- Google Search включается только существующей комбинацией глубокого режима и поиска; может тарифицироваться отдельно. Допуск к глубокому режиму через AI_PAID_ENABLED/AI_PAID_USER_IDS сохранён.
- OpenRouter data_collection/список провайдеров не являются настройками Google. Правила хранения/использования данных нужно проверить в Google до отправки учебных данных. При `AI_REQUIRE_ZDR=true` прямой режим блокируется, поскольку интеграция не подтверждает эквивалентный режим ZDR.
- Для возврата к OpenRouter задайте `AI_PROVIDER=openrouter` и сделайте Redeploy. Сохранённый ключ OpenRouter не меняется.

Документация: https://ai.google.dev/api/generate-content, https://ai.google.dev/gemini-api/docs/document-processing, https://ai.google.dev/gemini-api/docs/billing.
